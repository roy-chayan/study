ধারণামনে রাখো
সন্ধি মানে মিলন — পাশাপাশি দুটি ধ্বনির মিলনআলোচিত হয় ধ্বনিতত্ত্বে। প্রধান কাজ ধ্বনি পরিবর্তন, প্রধান সুবিধা উচ্চারণ সহজ হওয়া।১৩তম নিবন্ধন১৫তম নিবন্ধন১৬তম নিবন্ধন১৭তম নিবন্ধন১৮তম নিবন্ধন
সমাস মানে সংক্ষেপণ — পাশাপাশি দুটি পদের মিলনআলোচিত হয় রূপতত্ত্বে। সমাসের রীতি এসেছে সংস্কৃত থেকে।৯ম নিবন্ধন১১তম নিবন্ধন১৭তম নিবন্ধন
বাংলা ক্রিয়াপদের সঙ্গে সন্ধি হয় নাসন্ধি হয় বিশেষ্য, বিশেষণ, অব্যয়ের সঙ্গে।১৪তম নিবন্ধন

স্বরসন্ধি

স্বরের সঙ্গে স্বরের মিলন।

নিয়মউদাহরণ
অ/আ + অ/আ = আহিম + আলয় = হিমালয়১২তম নিবন্ধন
অ + ঐ = ঐমত + ঐক্য = মতৈক্য১০ম নিবন্ধন
ই/ঈ + ই/ঈ = ঈসতী + ঈশ = সতীশ (দুটোই দীর্ঘ ঈ)১২তম নিবন্ধন১৮তম নিবন্ধন
অ + ঈ = এ · আ + ঈ = এপরম + ঈশ = পরমেশ · ঢাকা + ঈশ্বরী = ঢাকেশ্বরী১৭তম নিবন্ধন৫০তম বিসিএস
ই + অন্য স্বর = য-ফলাপ্রতি + আবর্তন = প্রত্যাবর্তন · বি + অর্থ = ব্যর্থ১৭তম নিবন্ধন
ও + অ = অব · ও + এ = অবেলো + অন = লবণ · গো + এষণা = গবেষণা১১তম নিবন্ধন১২তম নিবন্ধন১৬তম নিবন্ধন
ঔ + অ = আব · ঐ + অ = আয়পৌ + অক = পাবক · গৈ + অক = গায়ক — এ দুটি নিয়মমাফিক

অংশ ৩

ব্যঞ্জনসন্ধি

যেকোনো একদিকে ব্যঞ্জন — আর খাঁটি বাংলা সন্ধি।

নিয়মউদাহরণ
ত্ + চ = চ্চচলৎ + চিত্র = চলচ্চিত্র১১তম নিবন্ধন১৮তম নিবন্ধন
ত্ + শ = চ্ছউৎ + শ্বাস = উচ্ছ্বাস — দুই দিকেই ব্যঞ্জন, তাই ব্যঞ্জনসন্ধি১১তম নিবন্ধন
জ্ + ন = জ্ঞরাজ্ + নী = রাজ্ঞী১৪তম নিবন্ধন
ষ্ + ত = ষ্ট · ষ্ + থ = ষ্ঠকৃষ্ + তি = কৃষ্টি · ষষ্ + থ = ষষ্ঠ১৩তম নিবন্ধন১৭তম নিবন্ধন
ট্ + স্বর → ড়ষট্ + ঋতু = ষড়ঋতু (হসন্ত ছাড়া লিখলে ভুল)১০ম নিবন্ধন
ম্ + ব → ংসম্ + বাদ = সংবাদ১৬তম নিবন্ধন
মূল শব্দ ভাস্ভাস্ + বর = ভাস্বর১৫তম নিবন্ধন
দিব্ বদলে দ্যুদিব্ + লোক = দ্যুলোক১৬তম নিবন্ধন
খাঁটি বাংলা সন্ধি — সমীভবনকাঁদ + না = কান্না: দুটি ভিন্ন ব্যঞ্জন একই রকম হয়ে যায়১২তম নিবন্ধন১৫তম নিবন্ধন

বিসর্গসন্ধি

বিসর্গ (ঃ) পরের ধ্বনি অনুযায়ী বদলায়।

নিয়মউদাহরণ
ঃ + ত = স্তমনঃ + তাপ = মনস্তাপ১১তম নিবন্ধন
ঃ + ছ = শ্ছশিরঃ + ছেদ = শিরশ্ছেদ৪৬তম বিসিএস
উঃ + প = ষ্পচতুঃ + পদ = চতুষ্পদ১৩তম নিবন্ধন১৭তম নিবন্ধন
ঃ + য (ঘোষ ধ্বনি) = র্দুঃ + যোগ = দুর্যোগ১৩তম নিবন্ধন১৪তম নিবন্ধন
ঃ + র → বিসর্গ লোপ, আগের স্বর দীর্ঘনিঃ + রোগ = নীরোগ১৫তম নিবন্ধন

অংশ ৫

নিপাতনে সিদ্ধ ও ধ্বনি পরিবর্তন

নিয়ম না মেনে যে সন্ধি প্রচলিত — প্রায় প্রতি বছর একটি প্রশ্ন।

নিয়মউদাহরণ
নিয়ম মানে না — নিপাতনে সিদ্ধপরস্পর · বনস্পতি (বন + পতি) · গবাক্ষ (গো + অক্ষ) · কুলটা (কুল + অটা) · মার্তণ্ড · অন্যান্য১১তম নিবন্ধন১২তম নিবন্ধন১৪তম নিবন্ধন১৫তম নিবন্ধন১৮তম নিবন্ধন৪৪তম বিসিএস
স্বরভক্তি — যুক্তব্যঞ্জনের মাঝে স্বর আসেরত্ন > রতন১৫তম নিবন্ধন
চ-বর্গের (চ, জ) নাসিক্য ঞ — তালব্য ধ্বনিপঞ্চ, গঞ্জ১৭তম নিবন্ধন

ফাঁদ: “নিপাতনে সিদ্ধ নয় কোনটি” প্রশ্নে নিয়মমাফিকটি খোঁজো — মসী + আধার = মস্যাধার (ঈ + আ = য-ফলা + আ-কার)। আর বনস্পতি নিয়ে মতভেদ আছে: ব্যাকরণ বইয়ে বন + পতি (নিপাতনে সিদ্ধ), কোনো অভিধানে বনঃ + পতি; অপশনে যেটি আছে সেটি দেখো।

সমাসের পরিভাষা

সমস্যমান পদ, সমস্ত পদ, ব্যাসবাক্য — আর কোন সমাসে কোন পদ প্রধান।

পরিভাষামানে
সমস্যমান পদযে পদগুলো মিলে সমাস হয়৮ম নিবন্ধন
সমস্ত পদসমাসে তৈরি নতুন পদ — দম্পতি, ছাড়পত্র৭ম নিবন্ধন৮ম নিবন্ধন১৬তম নিবন্ধন১৭তম নিবন্ধন
ব্যাসবাক্যসমস্ত পদকে ভেঙে যে বাক্যাংশ — যেমন জায়া ও পতি; অপর নাম বিগ্রহবাক্য১২তম নিবন্ধন
হাইফেন (-)সমাসবদ্ধ পদের অংশ আলাদা দেখাতে — শ্রদ্ধা-অভিনন্দন১৩তম নিবন্ধন১৬তম নিবন্ধন
ণত্ব বিধানসমাসবদ্ধ পদে সাধারণত খাটে না — অগ্রনায়ক১৬তম নিবন্ধন

কোন পদ প্রধান: পূর্বপদ — অব্যয়ীভাব; পরপদ — তৎপুরুষ, কর্মধারয়, দ্বিগু; উভয় পদ — দ্বন্দ্ব; অন্য পদ — বহুব্রীহি।৭ম নিবন্ধন৮ম নিবন্ধন৯ম নিবন্ধন১২তম নিবন্ধন১৬তম নিবন্ধন১৮তম নিবন্ধন

অংশ ৭

সমাসের প্রকার

ব্যাসবাক্য দেখেই সমাস চেনা যায় — প্রতিটি উদাহরণ বিগত প্রশ্ন থেকে।

সমাসউদাহরণ
দ্বন্দ্ব — উভয় পদ প্রধানমাতা ও পিতা = মাতাপিতা · অলুক দ্বন্দ্ব (বিভক্তি থাকে): দুধে-ভাতে১০ম নিবন্ধন
কর্মধারয় — বিশেষণ-বিশেষ্য, পরপদ প্রধাননব যে পৃথিবী = নবপৃথিবী · যা কাঁচা তাই মিঠা = কাঁচামিঠা · বাটা যে লঙ্কা = লঙ্কাবাটা৭ম নিবন্ধন৮ম নিবন্ধন
মধ্যপদলোপী কর্মধারয় — মাঝের পদ লোপ পায়সিংহ চিহ্নিত আসন = সিংহাসন · মৌ সংগ্রহকারী মাছি = মৌমাছি · মুজিববর্ষ · চিকিৎসাশাস্ত্র৮ম নিবন্ধন১৩তম নিবন্ধন১৬তম নিবন্ধন১৭তম নিবন্ধন৪২তম বিসিএস৪৩তম বিসিএস
উপমান কর্মধারয় — উপমান + সাধারণ গুণতুষারের ন্যায় শুভ্র = তুষারশুভ্র · শশকের ন্যায় ব্যস্ত = শশব্যস্ত · অরুণের ন্যায় রাঙা = অরুণরাঙা৯ম নিবন্ধন১৫তম নিবন্ধন৪১তম বিসিএস
উপমিত কর্মধারয় — সাধারণ গুণের উল্লেখ নেইমুখ চাঁদের ন্যায় = চাঁদমুখ · পুরুষ সিংহের ন্যায় = সিংহপুরুষ · কর পল্লবের ন্যায় = করপল্লব৮ম নিবন্ধন১০ম নিবন্ধন১২তম নিবন্ধন১৩তম নিবন্ধন১৮তম নিবন্ধন
রূপক কর্মধারয় — একটিকে অন্যটির রূপে কল্পনাকাল রূপ স্রোত = কালস্রোত১৬তম নিবন্ধন
তৎপুরুষ — পূর্বপদের বিভক্তি লোপ, পরপদ প্রধানধানের ক্ষেত (ষষ্ঠী) · মধু দিয়ে মাখা = মধুমাখা · তপের নিমিত্ত বন = তপোবন (চতুর্থী) · জন্ম থেকে অন্ধ = জন্মান্ধ · পথের রাজা = রাজপথ১০ম নিবন্ধন১১তম নিবন্ধন১৩তম নিবন্ধন১৬তম নিবন্ধন১৮তম নিবন্ধন৫০তম বিসিএস
নঞ তৎপুরুষ — না-বোধক পূর্বপদনয় আইনি = বেআইনি · বেতার · ন এক = অনেক১০ম নিবন্ধন১৫তম নিবন্ধন৫০তম বিসিএস
উপপদ তৎপুরুষ — উপপদ + কৃদন্ত পদনীল করে যে = নীলকর · ছেলে ধরে যে = ছেলেধরা৭ম নিবন্ধন১৪তম নিবন্ধন১৭তম নিবন্ধন৪৬তম বিসিএস
দ্বিগু — সংখ্যাবাচক পূর্বপদ, সমাহার অর্থেসাত সমুদ্রের সমাহার = সাতসমুদ্র · তে (তিন) প্রান্তরের সমাহার = তেপান্তর · সপ্ত অহের সমাহার = সপ্তাহ৭ম নিবন্ধন৮ম নিবন্ধন১৩তম নিবন্ধন১৮তম নিবন্ধন
বহুব্রীহি — অন্য কোনো পদ প্রধানবিগত মন যার = বিমনা · আশীতে বিষ যার = আশীবিষ · চৌচালা · নীল অম্বর যার = নীলাম্বর · কৃত বিদ্যা যার = কৃতবিদ্য · বিপত্নীক৭ম নিবন্ধন৮ম নিবন্ধন৯ম নিবন্ধন১১তম নিবন্ধন১২তম নিবন্ধন১৪তম নিবন্ধন১৬তম নিবন্ধন
