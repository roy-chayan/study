অংশ ১

কারক ও বিভক্তি

কারক হলো সম্পর্ক, বিভক্তি হলো চিহ্ন — দুটো আলাদা করে চেনো।

ধারণামনে রাখো
কারক — ক্রিয়ার সঙ্গে নামপদের সম্পর্কআলোচিত হয় বাক্যতত্ত্বে · ছয়টি: কর্তা, কর্ম, করণ, সম্প্রদান, অপাদান, অধিকরণ১৪তম নিবন্ধন
বিভক্তি — শব্দের শেষে যুক্ত বর্ণবিভক্তিযুক্ত শব্দ = পদ (সরোবর + এ = সরোবরে) · বিভক্তিহীন নামশব্দ = প্রাতিপদিক · অপ্রাণিবাচক শব্দে সাধারণত শূন্য বিভক্তি১৫তম নিবন্ধন১৭তম নিবন্ধন৪৬তম বিসিএস
অনুসর্গ — বিভক্তির কাজ করে এমন অব্যয়দ্বারা, দিয়ে, থেকে, জন্য১৮তম নিবন্ধন
সম্বন্ধ পদ কারক নয়সম্বন্ধ পদে ‘র, এর’ বিভক্তি · রবীন্দ্রনাথ সম্প্রদান কারক বাদ দিতে চেয়েছিলেন১৬তম নিবন্ধন৪৩তম বিসিএস

অংশ ২

ছয় কারক — প্রশ্ন করে চেনো

ক্রিয়াকে প্রশ্ন করো; উত্তর যে শব্দ, সেটিই সেই কারক। বিভক্তি দেখো শব্দের শেষে।

কারক — প্রশ্ন করোবিগত প্রশ্নের উদাহরণ
কর্তা — কে বা কী করে?জল পড়ে (শূন্য) · জল নামছে (শূন্য) · গরুতে দুধ দেয় (৭মী) · আমার যাওয়া হয়নি (৬ষ্ঠী) · ব্যতিহার কর্তা: বাঘে-মহিষে এক ঘাটে জল খায়, রাজায় রাজায় লড়াই১০ম নিবন্ধন১১তম নিবন্ধন১৫তম নিবন্ধন১৬তম নিবন্ধন১৭তম নিবন্ধন
কর্ম — কী বা কাকে?ডাক্তার ডাক (শূন্য) · ছাত্রটিকে জরিমানা (২য়া) · জিজ্ঞাসিব জনে জনে (৭মী) · করব কারে দান (৭মী) · সমধাতুজ কর্ম: এমন ঘুম ঘুমিয়েছি১১তম নিবন্ধন১২তম নিবন্ধন১৩তম নিবন্ধন১৫তম নিবন্ধন১৮তম নিবন্ধন৫০তম বিসিএস
করণ — কী দিয়ে?ফুলে ফুলে ঘর ভরেছে (৭মী) · অহঙ্কার পতনের মূল (শূন্য)১০ম নিবন্ধন১২তম নিবন্ধন১৩তম নিবন্ধন১৭তম নিবন্ধন
সম্প্রদান — স্বত্ব ত্যাগ করে কাকে দান?ভিখারিকে ভিক্ষা দাও (৪র্থী) · অন্ধজনে দেহ আলো (৭মী)১০ম নিবন্ধন১২তম নিবন্ধন১৬তম নিবন্ধন
অপাদান — কোথা থেকে, কী থেকে, কাকে ভয়?গাড়ি স্টেশন ছাড়ল (শূন্য) · তিলে তৈল হয় (৭মী) · পাপে বিরত থাকো (৭মী) · ভিখারী রাঘবে ডরাই (৭মী) · লোভে পাপ১০ম নিবন্ধন১২তম নিবন্ধন১৩তম নিবন্ধন১৪তম নিবন্ধন১৬তম নিবন্ধন১৭তম নিবন্ধন১৮তম নিবন্ধন
অধিকরণ — কোথায়, কখন, কোন বিষয়ে?পড়ায় মন বসে না · পড়াশোনায় মন দাও · উদ্যম বিহনে · তিলে তেল আছে · বাবা বাড়ি নেই (শূন্য) · খিলিপানের ভেতরে ওষুধ · পুকুরে মাছ আছে, আকাশে চাঁদ উঠেছে — ঐকদেশিক (সামীপ্য অর্থেও)১২তম নিবন্ধন১৩তম নিবন্ধন১৪তম নিবন্ধন১৫তম নিবন্ধন১৬তম নিবন্ধন১৭তম নিবন্ধন১৮তম নিবন্ধন
ভাবে সপ্তমীচন্দ্রোদয়ে কুমুদিনী বিকশিত হয় — একটি কাজের পর আরেকটি১৬তম নিবন্ধন
নিমিত্তার্থে ষষ্ঠীস্বাধীনতার সংগ্রাম — স্বাধীনতার জন্য১৭তম নিবন্ধন

ফাঁদ: “তিলে তৈল হয়” — তিল থেকে তেল, তাই অপাদান; কিন্তু “তিলে তেল আছে” — তিলের মধ্যে, তাই অধিকরণ। “গাড়ি স্টেশন ছাড়ল” — স্টেশন থেকে সরে যাওয়া, তাই অপাদান; “কী ছাড়ল” ভেবে কর্ম ধরলে ভুল।

অংশ ৩

প্রত্যয়

কৃৎ না তদ্ধিত — ধাতুর পরে না শব্দের পরে।

নিয়মউদাহরণ
প্রত্যয় দুই প্রকারকৃৎ — ধাতুর পরে: √মিশ্ + উক = মিশুক, √কাঁদ্ + অন (বাংলা কৃৎ) · তদ্ধিত — শব্দের পরে: হাত + ল = হাতল, প্রচুর + য = প্রাচুর্য, মনু + ষ্ণ = মানব১০ম নিবন্ধন১১তম নিবন্ধন১২তম নিবন্ধন১৬তম নিবন্ধন১৮তম নিবন্ধন৪১তম বিসিএস
নিপাতনে সিদ্ধ ও প্রত্যয়সাধিতসূর্য + ষ্ণ = সৌর (নিপাতনে সিদ্ধ) · ঐকিক প্রত্যয়-সাধিত শব্দ১৫তম নিবন্ধন৪৬তম বিসিএস
ধাতুবাংলা ধাতু: কহ্ · নামধাতু (নাম শব্দ থেকে): বেতা৪৩তম বিসিএস৪৪তম বিসিএস
ষত্ব বিধানসাৎ প্রত্যয়ে মূর্ধন্য ষ হয় না — অগ্নিসাৎ১২তম নিবন্ধন
গুণ ও বৃদ্ধিকৃৎ-প্রকৃতির আদিস্বরের পরিবর্তন: মনু → মানব, শিশু → শৈশব১৫তম নিবন্ধন

অংশ ৪

প্রকৃতি-প্রত্যয়ের তালিকা

প্রতিটি শব্দ বিগত পরীক্ষায় এসেছে — ট্যাগে কোন পরীক্ষায়।

কৃৎ প্রত্যয় (ধাতু + প্রত্যয়)

দর্শক = √দৃশ্ + অক৯ম নিবন্ধনপাঠক = √পঠ্ + অক১২তম নিবন্ধনগায়ক = √গৈ + ণক১৩তম নিবন্ধনউক্তি = √বচ্ + ক্তি১০ম নিবন্ধন১১তম নিবন্ধনমুক্তি = √মুচ্ + ক্তি১২তম নিবন্ধন১৩তম নিবন্ধন১৭তম নিবন্ধনমুক্ত = √মুচ্ + ক্ত১১তম নিবন্ধন১৭তম নিবন্ধনসৃষ্টি = √সৃজ্ + তি১৪তম নিবন্ধনকৃষ্টি = √কৃষ্ + তি৪২তম বিসিএসবক্তব্য = √বচ্ + তব্য১০ম নিবন্ধন১৪তম নিবন্ধনকর্তব্য = √কৃ + তব্য১৮তম নিবন্ধনশ্রবণ = √শ্রু + অন১১তম নিবন্ধন১৭তম নিবন্ধননয়ন = √নী + অন১৩তম নিবন্ধনদর্শনীয় = √দৃশ্ + অনীয়১৬তম নিবন্ধনদীপ্যমান = √দীপ্ + শানচ্১৪তম নিবন্ধন১৫তম নিবন্ধনবর্ধমান = √বৃধ্ + মান১৮তম নিবন্ধনদাতা = √দা + তৃচ্১৭তম নিবন্ধনমাতা = √মা + তৃচ্১৮তম নিবন্ধন

তদ্ধিত প্রত্যয় (শব্দ + প্রত্যয়)

মানব = মনু + ষ্ণষ্ণ-তে আদিস্বর বৃদ্ধি১৩তম নিবন্ধন১৭তম নিবন্ধনশৈশব = শিশু + ষ্ণ১২তম নিবন্ধনমহিমা = মহৎ + ইমন১৩তম নিবন্ধননীলিমা = নীল + ইমন১৪তম নিবন্ধনপোদ্দারী = পোদ্দার + ঈবৃত্তি অর্থে ঈ১১তম নিবন্ধনজেলেনি = জেলে + নিপ্রত্যয়ে গঠিত স্ত্রীবাচক১২তম নিবন্ধন১৭তম নিবন্ধনমেধাবিনী = মেধাবী + নীনী প্রত্যয়ে লিঙ্গান্তর১৪তম নিবন্ধন
