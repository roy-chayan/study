মানুষের স্বভাব

সাক্ষী গোপাল → নিষ্ক্রিয় দর্শক৭ম নিবন্ধন১৪তম নিবন্ধন১৭তম নিবন্ধনধর্মের ষাঁড় → স্বেচ্ছাচারী৭ম নিবন্ধনখোদার খাসি → ভাবনাচিন্তাহীন৮ম নিবন্ধননদের চাঁদ → অহমিকাপূর্ণ নির্গুণ ব্যক্তিঅন্য পরীক্ষায়: সুন্দর অথচ অপদার্থ৯ম নিবন্ধন১৮তম নিবন্ধনশকুনি মামা → কুচক্রী১০ম নিবন্ধন১৪তম নিবন্ধনঘরের শত্রু বিভীষণ → যে গৃহবিবাদ করে১০ম নিবন্ধনভুষণ্ডির কাক → দীর্ঘজীবী১১তম নিবন্ধনগোবর গণেশ → নিরেট মূর্খ১৩তম নিবন্ধননেই আঁকড়া → একগুঁয়ে১৪তম নিবন্ধনহাড়-হাভাতে → হতভাগ্য১৫তম নিবন্ধনখয়ের খাঁ = ঢাকের কাঠি → চাটুকার১০ম নিবন্ধন১৬তম নিবন্ধনধামাধরা → তোষামোদকারী১৬তম নিবন্ধনআমড়াগাছি করা → অযথা তোষামোদ১৮তম নিবন্ধনলেফাফা দুরস্ত → বাইরে ঠাট বজায় রাখে যে১৬তম নিবন্ধনকেতা দুরস্ত → পরিপাটি১৩তম নিবন্ধনঢাকের বায়া → মূল্যহীন৭ম নিবন্ধন১৮তম নিবন্ধনবিষ নেই তার কুলোপনা চক্কর → অক্ষমের বৃথা আস্ফালন৭ম নিবন্ধনঅসারের তর্জন-গর্জন সার → গুণহীনের ব্যর্থ আস্ফালন১৬তম নিবন্ধন

অবস্থা ও ঘটনা

রাবণের চিতা → চির অশান্তি৮ম নিবন্ধন৯ম নিবন্ধন১৭তম নিবন্ধনউজানের কৈ → সহজলভ্য১০ম নিবন্ধনহাত ধুয়ে বসা → নিশ্চিন্ত বোধ করাআশা ছেড়ে দেওয়া১১তম নিবন্ধনপুকুর চুরি → বড় ধরনের চুরি১১তম নিবন্ধনচক্ষুদান করা → চুরি করা১২তম নিবন্ধন১৫তম নিবন্ধনচাঁদের হাট → আনন্দের প্রাচুর্য১২তম নিবন্ধন১৩তম নিবন্ধনছকড়া নকড়া → সস্তা দর১৩তম নিবন্ধনহাতে দুর্বা গজানো → আলসেমির লক্ষণ১৪তম নিবন্ধনগদাই লস্করি চাল → আলসেমি১৭তম নিবন্ধনতাসের ঘর → ক্ষণস্থায়ী১৪তম নিবন্ধনতামার বিষ → অর্থের কুপ্রভাব১৪তম নিবন্ধন১৫তম নিবন্ধন১৬তম নিবন্ধনমন না মতি → অস্থির মানব মন১৫তম নিবন্ধনঢাক ঢাক গুড় গুড় → লুকোচুরি১৫তম নিবন্ধনশিরে সংক্রান্তি → আসন্ন বিপদ১৬তম নিবন্ধনসিঁদুরে মেঘ → বিপদের আশঙ্কা১৬তম নিবন্ধনসপ্তকাণ্ড রামায়ণ → বৃহৎ বিষয়১৬তম নিবন্ধন৪৩তম বিসিএসএকাদশে বৃহস্পতি → সুসময়১০ম নিবন্ধনঅর্ধচন্দ্র → গলাধাক্কা৪৪তম বিসিএসকাঁচায় না নোয়ালে বাঁশ, পাকলে করে ঠাস ঠাস → সময়ের কাজ সময়েপ্রবচন৮ম নিবন্ধনপত্রপাঠ → অবিলম্বে১৭তম নিবন্ধনভরাডুবি → সর্বনাশ১৮তম নিবন্ধনআকাশ কুসুম → অসম্ভব কল্পনা১৮তম নিবন্ধনগৌরচন্দ্রিকা → ভূমিকা৭ম নিবন্ধনগড্ডলিকা প্রবাহ → গড্ডল = ভেড়াঅন্ধ অনুকরণ৪৩তম বিসিএস৪৭তম বিসিএস

জোড়া ও বিপরীত বাগধারা

ইঁদুর কপাল ✕ একাদশে বৃহস্পতিমন্দভাগ্য ✕ সৌভাগ্য৭ম নিবন্ধনদহরম মহরম ✕ অহিনকুলঘনিষ্ঠতা ✕ চিরশত্রুতা১৩তম নিবন্ধনসুখের পায়রা · শরতের শিশির · লক্ষ্মীর বরযাত্রী → সুসময়ের বন্ধুখেউর গাওয়া আলাদা — অশ্লীল কথা৭ম নিবন্ধনবকধার্মিক = বিড়াল তপস্বী = তুলসী বনের বাঘ → ভণ্ডভিজা বিড়াল আলাদা; ব্যাঙের আধুলি (তুচ্ছ সম্পদে গর্ব) ≠ ব্যাঙের সর্দি (অসম্ভব ব্যাপার)৮ম নিবন্ধন১২তম নিবন্ধন

প্রকৃতি

পৃথিবী → পৃথ্বী, মেদিনী, ধরিত্রী, অবনী, ধরণীপ্রাণদ, ভূধর (পর্বত) নয়৮ম নিবন্ধন১০ম নিবন্ধন১৭তম নিবন্ধন১৮তম নিবন্ধনসমুদ্র → পাথার, অর্ণব, জলধিভূপতি (রাজা) নয়৮ম নিবন্ধন১০ম নিবন্ধনমেঘ → বারিদ, অম্বুদ৭ম নিবন্ধন১৬তম নিবন্ধনচাঁদ → বিধু, সোম, হিমাংশু, দ্বিজরাজসবিতা (সূর্য) নয়৭ম নিবন্ধন১১তম নিবন্ধন১৩তম নিবন্ধন১৫তম নিবন্ধন১৬তম নিবন্ধনসূর্য → তপন, প্রভাকর, অর্ক, আদিত্যঅর্ণব (সমুদ্র) নয়১০ম নিবন্ধন১৪তম নিবন্ধনআগুন → অনল, পাবক, বহ্নি, হুতাশন, কৃশানু, বায়ুসখা, বৈশ্বানরদ্যুতি, আবীর, পবন নয়১১তম নিবন্ধন১৪তম নিবন্ধন১৬তম নিবন্ধন১৮তম নিবন্ধন৪৪তম বিসিএসপানি → সলিল, অম্বু, পয়ঃ, অপ১২তম নিবন্ধন১৫তম নিবন্ধন১৬তম নিবন্ধনআকাশ → অম্বর, অন্তরীক্ষ, নভঃ৯ম নিবন্ধন১২তম নিবন্ধন১৪তম নিবন্ধননদী → সরিৎ, তটিনী১৩তম নিবন্ধন৪৬তম বিসিএসরাত্রি → শর্বরী, ত্রিযামা, ক্ষণদাভানু (সূর্য) নয়৯ম নিবন্ধন১৩তম নিবন্ধনপর্বত → শৈল, অদ্রি, অচলমেদিনী নয়১১তম নিবন্ধনস্বর্গ → ত্রিদিব, সুরপুর৫০তম বিসিএসজলাশয় → সরোবর১২তম নিবন্ধনগঙ্গা → প্রকাশিত উত্তর ‘সবগুলো’অপশনের গোমতী, কাবেরী আসলে অন্য নদী; গঙ্গার সমার্থক জাহ্নবী, ভাগীরথী১৬তম নিবন্ধন

প্রাণী, ফুল ও মানুষ

হাতি → কুঞ্জর, বারণ, হস্তী, করী, মাতঙ্গউরগ (সাপ) নয়৭ম নিবন্ধন১০ম নিবন্ধন১২তম নিবন্ধনপাখি → বিহগ, বিহঙ্গ, গরুড়নৃপ (রাজা) নয়১০ম নিবন্ধনঘোড়া → তুরঙ্গ১১তম নিবন্ধনসাপ → অহি১৫তম নিবন্ধনকোকিল → পিক, পরভৃত১৭তম নিবন্ধনফুল → প্রসূন, পুষ্প১৩তম নিবন্ধন১৫তম নিবন্ধনপদ্ম → পঙ্কজ, উৎপল১০ম নিবন্ধনকুঁড়ি → কোরক৭ম নিবন্ধনস্ত্রী → জায়া, অর্ধাঙ্গী, অর্ধাঙ্গিনী১৩তম নিবন্ধন১৭তম নিবন্ধনকন্যা → আত্মজা, দুহিতা, তনয়াপুত্র নয়১৮তম নিবন্ধনচুল → কুন্তল, কেশ১৮তম নিবন্ধনজ্যোৎস্না → কৌমুদী১৮তম নিবন্ধনদীপ্তি → অংশু৮ম নিবন্ধনপতাকা → কেতন১৩তম নিবন্ধনআমন্ত্রণ → আহ্বান, নিমন্ত্রণ, আবাহন১৫তম নিবন্ধনতাম্বুলিক → পান-ব্যবসায়ী, পর্ণকার, বারুইতামসিক নয়৪৫তম বিসিএসনিত্য → অহরহ৪৭তম বিসিএসভাত → তণ্ডুলতণ্ডুল আসলে চাল; অপশনে এটিই কাছাকাছি৫০তম বিসিএসসমার্থক নয় এমন জোড়া → অটবি (বন) — বিটপী (গাছ)১০ম নিবন্ধন

এক কথায় প্রকাশ

ইতিহাস বিষয়ে অভিজ্ঞ যিনি → ইতিহাসবেত্তাতিনটি প্রশ্নপত্রে৮ম নিবন্ধন১৪তম নিবন্ধন১৭তম নিবন্ধননূপুরের ধ্বনি → নিক্বণ১০ম নিবন্ধনযা বলা হয়নি → অনুক্তবলার অযোগ্য হলে অকথ্য১০ম নিবন্ধন১৮তম নিবন্ধনদীপ্তি পাচ্ছে এমন → দেদীপ্যমান১১তম নিবন্ধননষ্ট হওয়া স্বভাব যার → নশ্বর১২তম নিবন্ধননষ্ট হওয়া স্বভাব নয় যার → অবিনশ্বর১১তম নিবন্ধনসকলের জন্য প্রযোজ্য, সকলের হিতকর → সর্বজনীনসার্বজনীন নয়১২তম নিবন্ধন১৩তম নিবন্ধনহিংস্র জন্তুতে পরিপূর্ণ বন → শ্বাপদসংকুল১২তম নিবন্ধনগাছে উঠতে পটু → গেছো১২তম নিবন্ধনউপকারীর অপকার করে যে → কৃতঘ্ন১৩তম নিবন্ধনশত্রুকে দমন করে যে → অরিন্দম১৩তম নিবন্ধনশুভক্ষণে জন্ম যার → ক্ষণজন্মা১৪তম নিবন্ধনবীরসন্তান প্রসব করে যে নারী → বীরপ্রসূ১৪তম নিবন্ধন১৫তম নিবন্ধনসম্মুখে অগ্রসর হয়ে অভ্যর্থনা → প্রত্যুদ্গমন১৬তম নিবন্ধনসাপের খোলস → নির্মোক১২তম নিবন্ধন১৫তম নিবন্ধন১৬তম নিবন্ধনকর্মে অতিশয় তৎপর → ত্বরিৎকর্মা১৭তম নিবন্ধনদেখা যায়নি যা → অদৃষ্টযা দেখা যায় না — অদৃশ্য১৮তম নিবন্ধনঅন্যদিকে মন নেই যার → অনন্যমনা১৮তম নিবন্ধনন্যায়শাস্ত্র জানেন যিনি → নৈয়ায়িক৪২তম বিসিএসআকাশ ও পৃথিবীর অন্তরাল → রোদসী৫০তম বিসিএসমেঘের ধ্বনি → জীমূতমন্দ্র১৬তম নিবন্ধনযে মেয়ের বিয়ে হয়নি → অনূঢ়া১১তম নিবন্ধন১৫তম নিবন্ধনপূর্বে ছিল এখন নেই → ভূতপূর্ব১৩তম নিবন্ধনহনন করার ইচ্ছা → জিঘাংসা১৫তম নিবন্ধনজয় করার ইচ্ছা → জিগীষা৪৪তম বিসিএসযা বলা হবে → বক্তব্য১৭তম নিবন্ধনযে নারীর হাসি পবিত্র → শুচিস্মিতা১৮তম নিবন্ধনমৃত্তিকা দিয়ে তৈরি → মৃন্ময়৪৪তম বিসিএস

শব্দার্থ
